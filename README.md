BookTrack – Library Book Tracking Application

About the Project

BookTrack is a web application designed to help students and librarians track library books, borrowing requests, returns, and due dates. It provides an organized way to check book availability and shelf locations and monitor overdue books.

Objectives

- Make it easier for students to search for books.
- Help students track their borrowing history and due dates.
- Help librarians manage book records and borrowing transactions.
- Keep book availability and shelf locations updated.
- Provide administrators with tools to manage accounts, settings, and reports.

User Roles

Student

- Search for books by title or author.
- View book details, availability, and shelf locations.
- Submit borrowing requests.
- View personal borrowing history and due dates.
- Receive overdue alerts.

Librarian

- Add, edit, and remove book records.
- Confirm borrowing requests.
- Record returned books.
- Update book shelf locations.
- View borrowed and overdue books.

Admin

- Manage user accounts and roles.
- Configure system settings.
- View activity logs and reports.
- Back up and restore the database.

Project Scope

BookTrack focuses on book catalog management, borrowing and return tracking, shelf location management, and role-based access for students, librarians, and administrators.
